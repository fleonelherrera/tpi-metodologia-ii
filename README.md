# Sistema de Gestión de Solicitudes Académicas

Proyecto realizado para el Trabajo Práctico Integrador de Metodología de Sistemas II.

El sistema permite registrar solicitudes académicas, cambiar su estado, asignar responsables, buscar por prioridad y generar un reporte básico.

## Estructura

- `INICIAL`: versión base con problemas de diseño identificables.
- `REFACTORIZADO`: versión mejorada aplicando SOLID, Clean Code y refactoring.
- `docs`: diagnóstico, pruebas y checklist de code review.

## Ejecución

Desde cada una de las carpetas de código:

```text
javac *.java
java MainInicial
java PruebaSistemaInicial
```

Para la versión refactorizada:

```text
javac *.java
java MainRefactorizado
java PruebaSistemaRefactorizado
```
